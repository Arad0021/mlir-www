mlir::Operation *  op,
GetLayoutFnTy  getLayoutOfValue

static

Update an operation with the layout of its results.

For a vector result a temporary layout attribute is added to the op; for a tensor descriptor result the layout is written into its type.

If the global propagation left a result without a layout, forward-fill it locally from the operand layouts.
