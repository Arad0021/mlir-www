Returns a sparsity rank for loop ordering: lower values indicate dimensions that should be placed in outer loops.

When preferDenseOuter is true the ranking is 0 = Dense, 1 = Compressed, 2 = Singleton, 3 = Other/Unknown. Otherwise 0 = Singleton, 1 = Compressed, 2 = Dense, 3 = Other/Unknown.
