9 // This file declares the NVVM IR dialect in MLIR with all its ops, attributes
10 // and enums. The NVVM dialect only contains GPU specific additions on top of
11 // the general LLVM dialect.
12 //
13 // Prefer the narrower headers: this umbrella header only exists for
14 // compatibility. Including all ops of the NVVM dialect is expensive to compile,
15 // so include this header only if most of the headers below are needed anyway.
16 // Otherwise include:
17 // - NVVMDialectDecl.h for the dialect, NVVMAttributes.h for its attributes
18 // and enums, and NVVMRequiresSMTraits.h for its traits,
19 // - NVVM<Partition>Ops.h for the ops of an op partition, e.g.
20 // NVVMIndexSRegOps.h for `nvvm.read.ptx.sreg.tid.x` and NVVMMmaOps.h for
21 // `nvvm.mma.sync`.
22 //
