Detailed Description

Represents the amdgpu gfx chipset version, e.g., gfx90a, gfx942, gfx1103.

Note that the leading digits form a decimal number, while the last two digits form a hexadecimal number. For example: gfx942 --> major = 9, minor = 0x4, stepping = 0x2 gfx90a --> major = 9, minor = 0x0, stepping = 0xa gfx1103 --> major = 11, minor = 0x0, stepping = 0x3

Deprecated:
Use mlir::ROCDL::TargetInfo instead, and rely on target features rather than about version numbers. Will be removed after one release.
